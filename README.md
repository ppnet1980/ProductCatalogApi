# ProductCatalogApi v1

## Overview

This demo version exposes a simple product catalog API with three endpoints.

## Endpoints

- `GET /products`
- `GET /products/{id}`
- `POST /products`

## Goal of this version

- establish the initial API contract
- provide a simple baseline for later changes in `v2` and `v3`

## Run

```powershell
dotnet run
```
